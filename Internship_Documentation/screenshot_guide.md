## 2. Best Practices for Professional Screenshots
1. **Aspect Ratio**: Maximize the application window before capturing to ensure high resolution.
2. **Clarity**: Ensure text, table column headers, and axis labels are crisp and readable.
3. **No Sensitive Info**: Make sure no personal passwords, private desktop icons, or unneeded browser tabs are captured.
